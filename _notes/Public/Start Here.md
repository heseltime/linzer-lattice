This is a demo of **Linzer Lattice**, a Jekyll theme for linked notes. Every page is a note, written in plain Markdown.

Follow a link and it opens beside this note instead of replacing it. Try [[Reading Horizontally]], then come back and try [[Writing Notes]]: the path branches.

To set up your own notes, read [[Writing Notes]] and [[Topics and Threads]]. To see why it looks like this, follow the other topic, [[The Idea]].
