Linzer Lattice is a free Jekyll theme by Jack Heseltine, made for [[volcel::https://heseltime.github.io/volcel/]], a personal notes site, and published so others can use it.

It builds on [[Jekyll Garden::https://github.com/Jekyll-Garden/jekyll-garden.github.io]] (MIT), and its reading model follows [[Andy Matuschak's working notes::https://notes.andymatuschak.org/]]. The code is MIT licensed: [[github.com/heseltime/linzer-lattice::https://github.com/heseltime/linzer-lattice]].
